# Contributing

Follow the repository constitution in [AGENTS.md](.ai/core/AGENTS.md) and the
standards applicable to the change.

Use the [PR description standard](docs/pull-requests.md) for future pull requests.
The repository [PR template](../.github/pull_request_template.md) provides the
Summary, Changes, Governance and Validation sections.

For Codex GitHub access and PR creation, follow the
[GitHub MCP and pull-request guide](docs/github-mcp.md). It covers configuration,
credential sources, verification and direct REST PR creation using the existing
`GITHUB_PAT_TOKEN`, verified with PR #208.
